# ece-type-shooter

> Side-scrolling submarine shoot'em up in C with Allegro 4: enemies, bullets, pixel collision map, score.

## Features
- Scrolling background, player submarine, up to 10 enemies that move and shoot back
- Bullet pool, bounding-box collisions + **pixel collision map** (`collisions.bmp`) for the terrain
- Score and game-over screen

## Build
Visual Studio + **Allegro 4.4.2** (not included: put the MSVC build of Allegro 4.4.2 next to the solution).
